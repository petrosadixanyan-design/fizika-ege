Выложено на GitHub Pages, добавлена проверка живого сайта

Живой адрес: https://petrosadixanyan-design.github.io/fizika-ege/
Ветка main — весь проект, gh-pages — папка site/.

Почему выложили: пользователь не смог открыть сайт с телефона.
Разбор нашёл три причины. Первая моя: сервер был запущен
с --bind 127.0.0.1, то есть отвечал только самому компьютеру.
Две другие всё равно бы не пустили телефон — домашняя сеть помечена
«Общедоступная», а для python стоят два запрещающих входящих правила
брандмауэра, и прав администратора нет.

tests/live.py проверяет живой адрес глазами телефона: загрузку,
догрузку данных темы, рисование формул, шрифты, шпаргалку, оффлайн
и отсутствие битых запросов. Прошла целиком: страница за 0,7 с.
