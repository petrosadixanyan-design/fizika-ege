# Формулы ЕГЭ · Физика

Сайт для телефона, чтобы **запоминать формулы ЕГЭ по физике**: справочник с разбором каждой
буквы, квизы по темам и карточки умного повторения. Работает без интернета, ставится
на домашний экран как приложение.

Содержание построено по официальному **кодификатору ЕГЭ 2026 (ФИПИ)**: 4 раздела, 16 тем,
127 элементов. У каждой формулы стоит её код (`1.1.6`), уровень (базовый или углублённый)
и номера заданий ЕГЭ, где она нужна.

## Что внутри

**Экран «Сегодня»** — одна большая кнопка «Повторить N формул», сколько дней до ЕГЭ
и насколько ты готов. Никаких «с чего начать».

**Формулы по темам** — 16 тем кодификатора. Внутри темы список формул, у каждой
точки «силы памяти» (●●●○○).

**Экран формулы** — главное, ради чего всё затевалось:
формула крупно → что значит каждая буква и в чём она измеряется (нажми на букву) →
**когда формула работает и когда НЕ работает** → как запомнить → про знаки →
типичная ошибка → откуда она берётся → пример с числами → график → связанные формулы.

**Повторение** — карточка, переворот, три кнопки: «Не помню», «С трудом», «Знаю».
Сайт сам решает, когда показать формулу снова, чтобы она не забылась, и подстраивает
расписание под дату твоего ЕГЭ.

**Квиз** — 10 вопросов по теме: что значит буква, в чём измеряется, какая запись верна
(среди похожих ловушек), что станет с величиной, если другую удвоить, можно ли применять
формулу в таком случае. После каждого ответа — разбор. Ошибся — формула вернётся
в повторение.

**Шпаргалка** (`spravochnik.html`) — всё одной страницей, работает без JavaScript
и печатается (Ctrl+P).

## Как добавить тему

1. Создай `site/data/t-<тема>.js` по образцу `t-kinematika.js` — там в начале файла
   описано каждое поле. Имя темы должно совпадать с `id` из `site/data/topics.js`.
2. Запусти сборку:
   ```powershell
   cd C:\Users\User\Desktop\claude\fizika_ege
   node tools/build.js
   ```
   Она нарисует формулы, пересоберёт шпаргалку, обновит оффлайн и прогонит проверки.
3. Если что-то не так — проверка скажет что именно, по-русски.

**Самое важное при наборе:**
- `code` бери из кодификатора — проверка сверяет его с официальной таблицей;
- кириллицу в формулах пиши **только** внутри `\text{…}`: `F_{\text{тр}}`;
- `powers` ставь **только** у формул-произведений. Если в формуле есть сложение
  (`x = x₀ + υt`), поле не ставится — иначе квиз задаст неверный вопрос;
- `traps` (неверные записи для квиза) пишутся руками: генератор их не выдумывает.

## Устройство

Чистые HTML, CSS и JavaScript. **Никакой сборки и никаких npm-пакетов на сайте.**
Из сети не грузится вообще ничего: шрифты системные, KaTeX лежит локально.

```
site/            то, что публикуется
  index.html     оболочка приложения
  spravochnik.html   шпаргалка (делает генератор)
  css/style.css
  js/            srs.js (повторение), quizgen.js (вопросы), store.js, data.js, render.js, app.js
  data/          topics.js и t-<тема>.js — руками; остальное делают генераторы
  vendor/        KaTeX: стили и шрифты
tools/           генераторы: build.js, render-formulas.js, prerender.js, make-sw.js,
                 kodifikator.py, icons.py
tests/           unit.js (быстро) и check.py (браузер)
review/          документы ФИПИ и скриншоты — НЕ публикуется
```

Формулы пишутся на LaTeX, но **KaTeX в браузер не попадает**: `tools/render-formulas.js`
прогоняет его в Node и кладёт в данные уже готовый HTML. Поэтому математика появляется
мгновенно, работает без JavaScript и без интернета.

Прогресс хранится в самом браузере (`localStorage`, ключи с приставкой `fizege:`),
без регистрации и сервера. На экране «Я» его можно выгрузить текстом и перенести
на другой телефон.

Подробности, принятые решения и подводные камни — в [HISTORY.md](HISTORY.md).

в том числе с мобильного интернета. Репозиторий:

Как обновить после правок:

```powershell
cd C:\Users\User\Desktop\claude\fizika_ege
node tools/build.js                                   # пересобрать
git add -A
git commit -F review/commit-msg.txt                   # русский текст только через файл
git push
git subtree push --prefix site origin gh-pages        # выложить папку site/
# через минуту проверить:
& "C:\Users\User\Desktop\claude\y2k_bot\.venv\Scripts\python.exe" tests/live.py
```

Ветка `main` — весь проект (с генераторами и проверками), ветка `gh-pages` — только папка
`site/`, то есть то, что видно в интернете.

> Смотреть сайт с телефона по локальному адресу (`192.168.1.*`) на этом компьютере
> не получится: домашняя сеть помечена «общедоступной», а для python стоят запрещающие
> правила брандмауэра. Поэтому телефон — только через живой адрес.
